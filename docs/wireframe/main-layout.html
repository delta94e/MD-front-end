Closures Deep Dive

Last updated: May 28, 2026 · 12 min read

What Are Closures?

A closure is the combination of a function bundled together with references to its surrounding state (the lexical environment). In other words, a closure gives you access to an outer function's scope from an inner function.

Closures are one of the most powerful features in JavaScript. Understanding them is essential for writing clean, efficient code.

How Closures Work

In JavaScript, every time a function is created, a closure is created. The closure contains the function body and the scope chain at the time of creation.

javascript 
function createCounter() {
  let count = 0;

  return {
    increment() {
      return ++count;
    },
    getCount() {
      return count;
    }
  };
}

const counter = createCounter();
console.log(counter.increment()); // 1
console.log(counter.getCount()); // 1

Lexical Scoping

Lexical scoping defines how variable names are resolved in nested functions. Each inner function has access to the variables of its parent function, forming a scope chain.

Common Patterns

  • Data privacy — encapsulate variables that can't be accessed externally
  • Function factories — create specialized functions from a generic one
  • Event handlers — retain state between event invocations
  • Partial application — fix some arguments of a function

Performance Considerations

Closures can lead to memory leaks if not handled carefully. The key rule: only keep references you need. Unnecessary references prevent garbage collection.

PatternMemory ImpactRecommendation
Simple closureLowSafe to use freely
Closure in loopMediumUse let instead of var
DOM + closureHighRemove event listeners on cleanup
Timer + closureMediumClear timers when done
