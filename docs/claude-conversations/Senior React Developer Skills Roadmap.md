## 1. Virtual DOM & Reconciliation Algorithm


### Concept chi tiết:


Virtual DOM là representation in-memory của real DOM, được React sử dụng để optimize rendering performance.


**Reconciliation Process:**


1. **Diffing Algorithm**: React so sánh current virtual DOM tree với previous version
2. **Key-based reconciliation**: Sử dụng keys để identify elements
3. **Batch updates**: Group multiple state changes thành single re-render
