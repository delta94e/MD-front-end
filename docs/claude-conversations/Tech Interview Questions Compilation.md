## Các Pattern quan trọng trong Frontend System Design:


### Kiến trúc chung:


1. **Component Architecture** - Thiết kế hệ thống component có thể tái sử dụng

3. **Data Flow** - Unidirectional data flow, Real-time updates
4. **Performance** - Code splitting, Lazy loading, Caching strategies
5. **Accessibility** - ARIA labels, Keyboard navigation
6. **Responsive Design** - Mobile-first approach, Breakpoints
7. **Security** - XSS prevention, CSRF protection, CORS handling
