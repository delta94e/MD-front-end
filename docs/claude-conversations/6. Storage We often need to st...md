## Mở Đầu: Tại Sao Storage Lại Quan Trọng Đến Vậy?

### 📖 JavaScript Memory Model: The Ultimate Transient Storage


🌱 **Nguồn Gốc & Motivation**:


Trước khi có bất kỳ storage mechanism nào, developers chỉ có JavaScript variables và objects. Đây chính là form of transient storage đơn giản nhất và cũng quan trọng nhất.


```javascript
// Đây chính là transient storage đầu tiên
let userPreferences = {
    theme: 'dark',
    language: 'en',
    notifications: true
};

// Data này chỉ tồn tại trong runtime
// Refresh page = mất hết
```


🔬 **Bản Chất & Mechanism**:


JavaScript Memory Model hoạt động theo **Heap & Stack architecture**:


```javascript
// Stack Memory (Fast, Limited)
function processUser() {
    let userId = 123;           // Primitive -> Stack
    let userName = "Alice";     // String -> Stack (nhưng value có thể ở Heap)

    // Heap Memory (Slower, Flexible)
    let userObject = {          // Object reference -> Stack
        id: userId,             // Object data -> Heap
        name: userName,
        preferences: {          // Nested object -> Heap
            theme: 'dark'
        }
    };

    return userObject; // Return reference, not actual data
}
```

💡 **Intuitive Understanding**:


Hãy nghĩ về JavaScript memory như một **office building**:


- **Stack**: Elevator (nhanh, nhưng limited capacity, LIFO)
- **Heap**: Office floors (flexible space, nhưng cần elevator để access)
- **Garbage Collector**: Cleaning service (tự động dọn dẹp unused items)

**V8 Engine Memory Management**:


```javascript
// V8 Engine internal process (pseudo-code)
class V8MemoryManager {
    constructor() {
        this.youngGeneration = new SemiSpace(); // Nơi objects mới sinh ra
        this.oldGeneration = new OldSpace();    // Nơi objects "già" sống
        this.largeObjectSpace = new LargeSpace(); // Objects > 512KB
    }

    allocateObject(size, type) {
        if (size > LARGE_OBJECT_THRESHOLD) {
            return this.largeObjectSpace.allocate(size);
        }

        // Hầu hết objects start ở young generation
        return this.youngGeneration.allocate(size);
    }

    performGarbageCollection() {
        // Minor GC: Clean young generation
        this.scavengeYoungGeneration();

        // Major GC: Clean old generation (expensive!)
        if (this.shouldRunMajorGC()) {
            this.markAndSweepOldGeneration();
        }
    }
}
```


**Performance Characteristics**:


- **Access Time**: O(1) - Direct memory address
- **Allocation**: O(1) for small objects, O(log n) for large
- **Deallocation**: Automatic via GC (cost varies)

### 🎯 Transient Storage Best Practices


**1. Object Pool Pattern** (từ Amazon's product search):


```javascript
class ObjectPool {
    constructor(createFn, resetFn, initialSize = 10) {
        this.createFn = createFn;
        this.resetFn = resetFn;
        this.pool = [];

        // Pre-allocate objects
        for (let i = 0; i < initialSize; i++) {
            this.pool.push(this.createFn());
        }
    }

    acquire() {
        if (this.pool.length > 0) {
            return this.pool.pop(); // Reuse existing
        }
        return this.createFn(); // Create new if needed
    }

    release(obj) {
        this.resetFn(obj); // Reset state
        this.pool.push(obj); // Return to pool
    }
}

// Usage in product search
const searchResultPool = new ObjectPool(
    () => ({ id: null, title: '', price: 0, image: '' }),
    (obj) => { obj.id = null; obj.title = ''; obj.price = 0; obj.image = ''; }
);
```


**2. Weak References Pattern** (từ Google's Gmail):


```javascript
class EmailCache {
    constructor() {
        // WeakMap tự động cleanup khi key objects bị GC
        this.attachments = new WeakMap();
        this.emailBodies = new WeakMap();
    }

    cacheAttachment(email, attachment) {
        let attachments = this.attachments.get(email);
        if (!attachments) {
            attachments = [];
            this.attachments.set(email, attachments);
        }
        attachments.push(attachment);
    }

    // No manual cleanup needed!
    // Khi email object bị GC, attachments cũng tự động cleanup
}
```

### 📖 Cookies: The OG of Web Storage


🌱 **Nguồn Gốc & Motivation**:


Năm 1994, Lou Montulli (engineer tại Netscape) đang struggle với một problem: làm sao để server nhớ user đã add gì vào shopping cart? HTTP là stateless, nên mỗi request đều như "lần đầu gặp".


**Historical Context**:


```
Timeline of Web Storage Evolution:
```

Lou Montulli nghĩ: "Tại sao không để browser 'nhớ' giúp một ít information?" Thế là **HTTP Cookies** ra đời.

```javascript
function canAccessCookie(cookie, currentOrigin) {

    if (!isValidDomain(cookie.domain, currentOrigin.domain)) {
```

### 📖 Web Storage API: localStorage và sessionStorage


🌱 **Nguồn Gốc & Motivation**:


Năm 2009, HTML5 Working Group gặp phải frustration: developers đang abuse cookies để store large amounts of data, làm slow mọi HTTP request. Cookie được design cho small bits of data (4KB), không phải để store entire application state.


**Problem với Cookies**:


```javascript
// Developer năm 2008 doing this (very bad!)
document.cookie = "userPrefs=" + JSON.stringify({
    theme: "dark",
    language: "en",
    recentSearches: ["laptop", "phone", "tablet", "headphones", "camera"],
    favoriteProducts: [/* 1000+ product IDs */],
    shoppingHistory: [/* Massive array */]
}); // Cookie này có thể 10KB+!

// Mỗi HTTP request đều carry this massive cookie!
fetch('/api/user-profile'); // Request size unnecessarily large
```


HTML5 Working Group tạo ra **Web Storage API** với 2 flavors:


- **localStorage**: Persistent across browser sessions
- **sessionStorage**: Clear khi close tab/window


🔬 **Bản Chất & Mechanism**:


Web Storage hoạt động theo **Synchronous Key-Value Store** model:


```javascript
// Browser internal implementation (pseudo-code)
class WebStorageImplementation {
    constructor(isSession = false) {
        this.isSession = isSession;
        this.storage = new Map(); // In-memory cho session
        this.persistentFile = isSession ? null : './localStorage.sqlite';
    }

    setItem(key, value) {
        // 1. Convert value to string
        const stringValue = String(value);

        // 2. Check quota (usually 5-10MB)
        if (this.getUsedSpace() + stringValue.length > this.quota) {
            throw new DOMException('QuotaExceededError');
        }

        // 3. Store in memory
        this.storage.set(key, stringValue);

        // 4. Persist to disk (localStorage only)
        if (!this.isSession) {
            this.persistToDisk(key, stringValue);
        }

        // 5. Fire storage event
        this.fireStorageEvent(key, this.storage.get(key), stringValue);
    }

    getItem(key) {
        return this.storage.get(key) || null;
    }

    removeItem(key) {
        const oldValue = this.storage.get(key);
        this.storage.delete(key);

        if (!this.isSession) {
            this.removeFromDisk(key);
        }

        this.fireStorageEvent(key, oldValue, null);
    }
}
```

```javascript
// Web Storage chỉ store strings, nên cần serialization
class SmartStorage {
    static set(key, value) {
        try {
            // Handle different data types
            let serialized;

            if (typeof value === 'string') {
                serialized = value;
            } else if (value instanceof Date) {
                serialized = JSON.stringify({ __type: 'Date', value: value.toISOString() });
            } else if (value instanceof Map) {

                });
            } else if (value instanceof Set) {

                });
            } else {

            }

            localStorage.setItem(key, serialized);
        } catch (error) {
            console.error('Storage error:', error);
            // Fallback strategies...
        }
    }

    static get(key) {
        try {
            const value = localStorage.getItem(key);
            if (value === null) return null;

            // Try to parse as JSON first
            const parsed = JSON.parse(value);

            // Handle special types
            if (parsed && typeof parsed === 'object' && parsed.__type) {
                switch (parsed.__type) {
                    case 'Date':

                    case 'Map':
                        return new Map(parsed.value);
                    case 'Set':
                        return new Set(parsed.value);
                }
            }

            return parsed;
        } catch {
            // Not JSON, return as string
            return localStorage.getItem(key);
        }
    }
}
```

🏭 **Production Reality - Google Drive's File Browser**:


```javascript
// Google Drive caches file metadata trong localStorage
class DriveFileCache {
    constructor() {
        this.CACHE_KEY = 'drive_file_cache';
        this.MAX_CACHE_SIZE = 5 * 1024 * 1024; // 5MB
        this.CACHE_EXPIRY = 30 * 60 * 1000; // 30 minutes
    }

    cacheFileList(folderId, files) {
        try {
            const cache = this.getCache();

            // Add timestamp cho expiry check
            cache[folderId] = {
                files: files,
                timestamp: Date.now(),
                size: JSON.stringify(files).length
            };

            // Check total cache size
            if (this.getCacheSize(cache) > this.MAX_CACHE_SIZE) {
                this.evictOldEntries(cache);
            }

            localStorage.setItem(this.CACHE_KEY, JSON.stringify(cache));
        } catch (error) {
            if (error.name === 'QuotaExceededError') {
                // Fallback: clear oldest entries
                this.clearOldCache();
                // Retry once
                this.cacheFileList(folderId, files);
            }
        }
    }

    getCachedFileList(folderId) {
        const cache = this.getCache();
        const entry = cache[folderId];

        if (!entry) return null;

        // Check expiry
        if (Date.now() - entry.timestamp > this.CACHE_EXPIRY) {
            delete cache[folderId];
            this.saveCache(cache);
            return null;
        }

        return entry.files;
    }

    evictOldEntries(cache) {
        // LRU eviction strategy
        const entries = Object.entries(cache)
            .sort(([,a], [,b]) => a.timestamp - b.timestamp);

        // Remove oldest 20%
        const toRemove = Math.ceil(entries.length * 0.2);
        for (let i = 0; i < toRemove; i++) {
            delete cache[entries[i][0]];
        }
    }
}
```

**Transaction Lifecycle**:


```javascript
// IndexedDB Transaction States
/*
Transaction Lifecycle:
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ PENDING │───▶│ ACTIVE  │───▶│COMMITTING│───▶│COMPLETED│
└─────────┘    └─────────┘    └─────────┘    └─────────┘
                      │                            ▲
                      │        ┌─────────┐         │
                      └───────▶│ ABORTED │─────────┘
                               └─────────┘
*/

class IDBTransaction {
    constructor(db, storeNames, mode) {
        this.state = 'PENDING';
        this.operations = [];
        this.mode = mode; // 'readonly', 'readwrite', 'versionchange'
    }

    async execute(operation) {
        if (this.state !== 'ACTIVE') {
            throw new DOMException('TransactionInactiveError');
        }

        try {
            // Add to operation queue
            this.operations.push(operation);

            // Execute immediately if possible
            const result = await this.processOperation(operation);

            // Auto-commit if no more operations pending
            if (this.operations.length === 0) {
                await this.commit();
            }

            return result;
        } catch (error) {
            await this.abort();
            throw error;
        }
    }

    async commit() {
        this.state = 'COMMITTING';

        // Flush all changes to disk
        await this.flushToDisk();

        this.state = 'COMPLETED';
        this.dispatchEvent('complete');
    }
}
```

```javascript
                chunkIndex: chunkIndex,
                data: await chunk.arrayBuffer() // Store as ArrayBuffer
```

```javascript
class IndexedDBPool {
    constructor(dbName, version, maxConnections = 5) {
        this.dbName = dbName;
        this.version = version;
        this.connections = [];
        this.maxConnections = maxConnections;
        this.waitingQueue = [];
    }

    async getConnection() {
        // Return existing connection if available
        if (this.connections.length > 0) {
            return this.connections.pop();
        }

        // Create new connection if under limit
        if (this.activeConnections < this.maxConnections) {
            return await this.createConnection();
        }

        // Wait for connection to be available
        return new Promise((resolve) => {
            this.waitingQueue.push(resolve);
        });
    }

    releaseConnection(db) {
        if (this.waitingQueue.length > 0) {
            const resolve = this.waitingQueue.shift();
            resolve(db);
        } else {
            this.connections.push(db);
        }
    }
}

class BatchProcessor {
    constructor(db) {
        this.db = db;
        this.batchSize = 1000;
    }

    async bulkInsert(storeName, records) {
        // Process in batches để avoid blocking UI
        for (let i = 0; i < records.length; i += this.batchSize) {
            const batch = records.slice(i, i + this.batchSize);

            const transaction = this.db.transaction([storeName], 'readwrite');
            const store = transaction.objectStore(storeName);

            // Add all records in single transaction
            const promises = batch.map(record =>
                new Promise((resolve, reject) => {
                    const request = store.add(record);
                    request.onsuccess = () => resolve();
                    request.onerror = () => reject(request.error);
                })
            );

            await Promise.all(promises);

            // Yield control để prevent UI freeze
            await new Promise(resolve => setTimeout(resolve, 0));
        }
```

```javascript
class FacebookSessionStore {
    constructor() {
        // Redis Cluster setup
        this.redis = new Redis.Cluster([
            { host: 'redis-1.facebook.com', port: 6379 },
            { host: 'redis-2.facebook.com', port: 6379 },
            { host: 'redis-3.facebook.com', port: 6379 },
        ], {
            retryDelayOnFailover: 100,
            maxRetriesPerRequest: 3,
            enableOfflineQueue: false
        });

        this.SESSION_TTL = 30 * 24 * 60 * 60; // 30 days
        this.CACHE_TTL = 15 * 60; // 15 minutes for frequently accessed data
    }

    async createSession(userId, deviceInfo) {
        const sessionId = this.generateSessionId();
        const sessionData = {
            userId: userId,
            deviceInfo: deviceInfo,
            createdAt: Date.now(),
            lastActivity: Date.now(),
            permissions: await this.getUserPermissions(userId),
            preferences: await this.getUserPreferences(userId)
        };

        // Multi-command transaction
        const pipeline = this.redis.pipeline();

        // Store session data
        pipeline.hmset(`session:${sessionId}`, sessionData);
        pipeline.expire(`session:${sessionId}`, this.SESSION_TTL);

        // User -> sessions mapping (for session management)
        pipeline.sadd(`user_sessions:${userId}`, sessionId);
        pipeline.expire(`user_sessions:${userId}`, this.SESSION_TTL);

        // Activity tracking
        pipeline.zadd('active_sessions', Date.now(), sessionId);

        await pipeline.exec();

        return sessionId;
    }

    async getSession(sessionId) {
        // Try L1 cache first (application memory)
        if (this.l1Cache.has(sessionId)) {
            return this.l1Cache.get(sessionId);
        }

        // L2 cache (Redis)
        const sessionData = await this.redis.hgetall(`session:${sessionId}`);

        if (!sessionData || Object.keys(sessionData).length === 0) {
            return null;
        }

        // Update last activity
        await this.redis.hset(`session:${sessionId}`, 'lastActivity', Date.now());

        // Cache in L1 for next request
        this.l1Cache.set(sessionId, sessionData, this.CACHE_TTL);

        return sessionData;
    }

    async invalidateUserSessions(userId, excludeSessionId = null) {
        // Get all user sessions
        const sessionIds = await this.redis.smembers(`user_sessions:${userId}`);

        const pipeline = this.redis.pipeline();

        for (const sessionId of sessionIds) {
            if (sessionId !== excludeSessionId) {
                // Delete session data
                pipeline.del(`session:${sessionId}`);

                // Remove from user sessions set
                pipeline.srem(`user_sessions:${userId}`, sessionId);

                // Remove from active sessions
                pipeline.zrem('active_sessions', sessionId);
            }
        }

        await pipeline.exec();

        // Clear L1 cache
        for (const sessionId of sessionIds) {
            if (sessionId !== excludeSessionId) {
                this.l1Cache.delete(sessionId);
            }
        }
    }

    // Rate limiting with sliding window
    async checkRateLimit(userId, action, windowMs = 60000, maxRequests = 100) {
        const key = `rate_limit:${userId}:${action}`;
        const now = Date.now();
        const windowStart = now - windowMs;

        const pipeline = this.redis.pipeline();

        // Remove old entries
        pipeline.zremrangebyscore(key, 0, windowStart);

        // Count current requests in window
        pipeline.zcard(key);

        // Add current request
        pipeline.zadd(key, now, `${now}-${Math.random()}`);

        // Set expiry
        pipeline.expire(key, Math.ceil(windowMs / 1000));

        const results = await pipeline.exec();
        const currentCount = results[1][1]; // Result of ZCARD

        return {
            allowed: currentCount < maxRequests,
            count: currentCount,
            resetTime: windowStart + windowMs
        };
    }
```

```javascript
// Database buffer pool (simplified implementation)
class BufferPool {
    constructor(size = 1000) { // 1000 pages
        this.pages = new Map(); // pageId -> Page
        this.lruList = new DoublyLinkedList();
        this.maxSize = size;
        this.dirtyPages = new Set();
    }

    async getPage(pageId) {
        // Check if page in memory
        if (this.pages.has(pageId)) {
            // Move to front of LRU list
            this.lruList.moveToFront(pageId);
            return this.pages.get(pageId);
        }

        // Page not in memory, need to load from disk
        if (this.pages.size >= this.maxSize) {
            await this.evictPage();
        }

        // Load page from disk
        const page = await this.loadPageFromDisk(pageId);
        this.pages.set(pageId, page);
        this.lruList.addToFront(pageId);

        return page;
    }

    async evictPage() {
        const lruPageId = this.lruList.removeLast();
        const page = this.pages.get(lruPageId);

        // Write dirty page to disk before eviction
        if (this.dirtyPages.has(lruPageId)) {
            await this.writePageToDisk(lruPageId, page);
            this.dirtyPages.delete(lruPageId);
        }

        this.pages.delete(lruPageId);
    }

    markDirty(pageId) {
        this.dirtyPages.add(pageId);
    }

    async flush() {
        // Write all dirty pages to disk
        for (const pageId of this.dirtyPages) {
            const page = this.pages.get(pageId);
            await this.writePageToDisk(pageId, page);
        }
        this.dirtyPages.clear();
    }
}
```

**Transaction Management**:


```javascript
// Transaction isolation levels
class TransactionManager {
    constructor() {
        this.transactions = new Map();
        this.lockManager = new LockManager();
        this.logManager = new LogManager();
    }

    async beginTransaction(isolationLevel = 'READ_COMMITTED') {
        const txnId = this.generateTxnId();
        const transaction = {
            id: txnId,
            isolationLevel: isolationLevel,
            readSet: new Set(),
            writeSet: new Set(),
            locks: new Set(),
            startTime: Date.now()
        };

        this.transactions.set(txnId, transaction);

        // Log transaction begin
        await this.logManager.log({
            type: 'BEGIN',
            txnId: txnId,
            timestamp: Date.now()
        });

        return txnId;
    }

    async readRow(txnId, tableId, rowId) {
        const transaction = this.transactions.get(txnId);

        // Apply isolation level rules
        switch (transaction.isolationLevel) {
            case 'READ_UNCOMMITTED':
                // No locks needed, dirty reads allowed
                return await this.getRowData(tableId, rowId);

            case 'READ_COMMITTED':
                // Shared lock on read, released immediately
                await this.lockManager.acquireSharedLock(txnId, tableId, rowId);
                const data = await this.getRowData(tableId, rowId);
                await this.lockManager.releaseLock(txnId, tableId, rowId);
                return data;

            case 'REPEATABLE_READ':
                // Shared lock held until transaction end
                await this.lockManager.acquireSharedLock(txnId, tableId, rowId);
                transaction.locks.add({ type: 'SHARED', tableId, rowId });
                transaction.readSet.add({ tableId, rowId });
                return await this.getRowData(tableId, rowId);

            case 'SERIALIZABLE':
                // Range locks to prevent phantom reads
                await this.lockManager.acquireRangeLock(txnId, tableId, rowId);
                transaction.locks.add({ type: 'RANGE', tableId, rowId });
                return await this.getRowData(tableId, rowId);
        }
    }

    async writeRow(txnId, tableId, rowId, data) {
        const transaction = this.transactions.get(txnId);

        // Acquire exclusive lock
        await this.lockManager.acquireExclusiveLock(txnId, tableId, rowId);
        transaction.locks.add({ type: 'EXCLUSIVE', tableId, rowId });

        // Log the write operation
        await this.logManager.log({
            type: 'UPDATE',
            txnId: txnId,
            tableId: tableId,
            rowId: rowId,
            oldData: await this.getRowData(tableId, rowId),
            newData: data,
            timestamp: Date.now()
        });

        // Perform the write
        await this.updateRowData(tableId, rowId, data);
        transaction.writeSet.add({ tableId, rowId, data });
    }

    async commitTransaction(txnId) {
        const transaction = this.transactions.get(txnId);

        try {
            // Phase 1: Prepare (validate)
            await this.validateTransaction(transaction);

            // Phase 2: Commit
            await this.logManager.log({
                type: 'COMMIT',
                txnId: txnId,
                timestamp: Date.now()
            });

            // Release all locks
            for (const lock of transaction.locks) {
                await this.lockManager.releaseLock(txnId, lock.tableId, lock.rowId);
            }

            this.transactions.delete(txnId);

        } catch (error) {
            await this.rollbackTransaction(txnId);
            throw error;
        }
    }
}
```

```javascript
                            this.queueForRetry(regionId, key, value);
                        });

                    replicationPromises.push(replicationPromise);
                }
            }

            // 3. Optional: Wait for synchronous replicas
            if (options.consistency === 'strong') {
                await Promise.all(replicationPromises);
            }

            return { success: true, region: primaryRegion };

        } catch (error) {
            // Failover to secondary region
            return await this.handlePrimaryFailure(key, value, options);
        }
    }

    async readData(key, options = {}) {
        // Read from nearest region for performance
        const nearestRegion = this.getNearestRegion(options.userLocation);

        try {
            const data = await this.readFromRegion(nearestRegion, key);

            if (data === null && options.fallbackToPrimary) {
                // Fallback to primary if data not found in nearest region
                const primaryRegion = this.getPrimaryRegion();
                return await this.readFromRegion(primaryRegion, key);
            }

            return data;

        } catch (error) {
            // Circuit breaker pattern - fail fast if region is down
            if (this.isRegionHealthy(nearestRegion)) {
                throw error;
            }

            // Fallback to healthy region
            const healthyRegion = this.getHealthyRegion();
            return await this.readFromRegion(healthyRegion, key);
        }
    }

    // Conflict resolution for concurrent writes
    resolveConflicts(localValue, remoteValue, timestamp) {
        // Last-write-wins strategy
        if (localValue.timestamp > remoteValue.timestamp) {
            return localValue;
        }

        if (remoteValue.timestamp > localValue.timestamp) {
            return remoteValue;
        }

        // Timestamps equal - use deterministic tiebreaker
```

```javascript
        this.counts = new Map(); // nodeId -> count
        this.counts.set(nodeId, 0);
    }

    increment() {

        this.counts.set(this.nodeId, current + 1);

    value() {
        let total = 0;
        for (const count of this.counts.values()) {
            total += count;
        }
        return total;
    }

        const allNodes = new Set([
            ...this.counts.keys(),
            ...other.counts.keys()

        for (const nodeId of allNodes) {
            const thisCount = this.counts.get(nodeId) || 0;
            const otherCount = other.counts.get(nodeId) || 0;
```

```javascript
            utilizationHistory: []
        };

        // Start monitoring
        this.startAdaptiveMonitoring();
    }

    async getConnection() {
        this.metrics.totalRequests++;
        const startTime = Date.now();

        // Check for idle connection first
        if (this.idleConnections.length > 0) {
            const connection = this.idleConnections.pop();
            this.activeConnections.add(connection);

            this.recordMetric('connectionTime', Date.now() - startTime);
            return connection;
        }

        // Create new connection if under limit
        if (this.activeConnections.size < this.currentSize) {
            const connection = await this.createConnection();
            this.activeConnections.add(connection);

            this.recordMetric('connectionTime', Date.now() - startTime);
            return connection;
        }

        // Wait in queue
        return new Promise((resolve, reject) => {
            const timeout = setTimeout(() => {
                reject(new Error('Connection timeout'));
            }, 30000);

            this.waitingQueue.push({
                resolve,
                reject,
                timeout,
                startTime
            });
        });
    }

    releaseConnection(connection) {
        this.activeConnections.delete(connection);

        // Serve waiting requests first
        if (this.waitingQueue.length > 0) {
            const request = this.waitingQueue.shift();
            clearTimeout(request.timeout);

            this.activeConnections.add(connection);
            this.recordMetric('queueTime', Date.now() - request.startTime);
            request.resolve(connection);

        } else {
            // Return to idle pool
            this.idleConnections.push(connection);
        }
    }

    // Adaptive pool sizing based on demand
    startAdaptiveMonitoring() {
        setInterval(() => {
            this.adjustPoolSize();
        }, 60000); // Every minute
    }

    adjustPoolSize() {
        const utilization = this.calculateUtilization();
        const averageQueueTime = this.getAverageQueueTime();

        // Scale up conditions
        if (utilization > 0.8 || averageQueueTime > 100) {
            if (this.currentSize < this.maxConnections) {
                this.scaleUp();
            }
        }

        // Scale down conditions
        if (utilization < 0.3 && averageQueueTime < 10) {
            if (this.currentSize > this.minConnections) {
                this.scaleDown();
            }
        }

        // Record utilization history
        this.metrics.utilizationHistory.push({
            timestamp: Date.now(),
            utilization: utilization,
            poolSize: this.currentSize
        });
    }

    scaleUp() {
        const newSize = Math.min(
            this.currentSize + Math.ceil(this.currentSize * 0.2), // 20% increase
            this.maxConnections
        );

        console.log(`Scaling connection pool UP: ${this.currentSize} -> ${newSize}`);
        this.currentSize = newSize;
    }

    scaleDown() {
        const newSize = Math.max(
            this.currentSize - Math.ceil(this.currentSize * 0.1), // 10% decrease
            this.minConnections
        );

        console.log(`Scaling connection pool DOWN: ${this.currentSize} -> ${newSize}`);
        this.currentSize = newSize;

        // Close excess idle connections
        while (this.idleConnections.length > newSize - this.activeConnections.size) {
```

```javascript
        const dek = await this.generateDataEncryptionKey();

        // 4. Encrypt DEK với user key
        const encryptedDEK = await this.encryption.encrypt(dek, userKey);

        // 5. Store encrypted DEK với data (envelope encryption)
        return {
            encryptedData: encryptedData,
            encryptedKey: encryptedDEK,
            algorithm: 'AES-256-GCM',
            keyDerivation: 'PBKDF2',
            timestamp: Date.now()
        };
    }

    // Field-level encryption for sensitive data
    async encryptSensitiveFields(record, schema) {
        const encrypted = { ...record };

        for (const [field, config] of Object.entries(schema.sensitiveFields)) {
            if (record[field]) {
                // Different encryption for different data types
                switch (config.type) {
                    case 'pii':
                        encrypted[field] = await this.encryptPII(record[field]);
                        encrypted[`${field}_hash`] = await this.hashForSearch(record[field]);
                        break;

                    case 'financial':
                        encrypted[field] = await this.encryptFinancial(record[field]);
                        break;

                    case 'medical':
                        encrypted[field] = await this.encryptMedical(record[field]);
                        break;
                }

                // Audit sensitive field access
                await this.audit.logSensitiveAccess({
                    field: field,
                    action: 'encrypt',
                    user: record.userId,
                    timestamp: Date.now()
                });
            }
        }

        return encrypted;
    }

    // Zero-trust access control
    async validateAccess(user, resource, operation) {
        // 1. Authentication check
        const authValid = await this.validateAuthentication(user);
        if (!authValid) {
            throw new SecurityError('Authentication failed');
        }

        // 2. Authorization check
        const authzValid = await this.validateAuthorization(user, resource, operation);
        if (!authzValid) {
            throw new SecurityError('Authorization failed');
        }

        // 3. Context-based validation
        const contextValid = await this.validateContext(user, operation);
        if (!contextValid) {
            throw new SecurityError('Context validation failed');
        }

        // 4. Rate limiting
        const rateLimitOk = await this.checkRateLimit(user, operation);
        if (!rateLimitOk) {
            throw new SecurityError('Rate limit exceeded');
        }

        // 5. Audit the access
        await this.audit.logAccess({
            user: user.id,
            resource: resource,
            operation: operation,
            timestamp: Date.now(),
            ip: user.ip,
            userAgent: user.userAgent
        });

        return true;
    }

        if (environment === 'production') {
            return data; // No masking in production
        }

        const masked = JSON.parse(JSON.stringify(data)); // Deep clone

        const maskingRules = {
            email: (email) => this.maskEmail(email),
            phone: (phone) => this.maskPhone(phone),
            ssn: (ssn) => this.maskSSN(ssn),
            creditCard: (cc) => this.maskCreditCard(cc),
            address: (addr) => this.maskAddress(addr)
        };

        return this.applyMaskingRules(masked, maskingRules);

    maskEmail(email) {
        const [local, domain] = email.split('@');
        const maskedLocal = local.charAt(0) + '*'.repeat(local.length - 2) + local.charAt(local.length - 1);
        return `${maskedLocal}@${domain}`;
    }

    async ensureCompliance(operation, data) {
        const complianceChecks = [];

        if (this.compliance.isGDPRApplicable(data)) {
            complianceChecks.push(await this.compliance.checkGDPR(operation, data));
        }

        // HIPAA compliance
        if (this.compliance.isHIPAAApplicable(data)) {

        }

        // PCI DSS compliance
        if (this.compliance.isPCIApplicable(data)) {
            complianceChecks.push(await this.compliance.checkPCI(operation, data));
        }

        const violations = complianceChecks.filter(check => !check.compliant);

        if (violations.length > 0) {
            throw new ComplianceError('Compliance violations detected', violations);
        }

        return true;
    }

    async createSecureBackup(data) {
        // 1. Encrypt backup data
        const backupKey = await this.generateBackupKey();
        const encryptedBackup = await this.encryption.encrypt(data, backupKey);

        // 2. Create integrity hash
        const integrityHash = await this.createIntegrityHash(encryptedBackup);

        // 3. Split backup across multiple locations
        const backupShards = await this.splitBackup(encryptedBackup, 3, 2); // 3 shards, 2 required

        // 4. Store in secure locations
        const storagePromises = backupShards.map((shard, index) =>
            this.storeBackupShard(shard, `location-${index}`)
        );

        await Promise.all(storagePromises);

        // 5. Store key securely (separate từ data)
        await this.storeBackupKey(backupKey);

        return {
            backupId: this.generateBackupId(),
            timestamp: Date.now(),
            integrityHash: integrityHash,
            shardCount: backupShards.length,
            encrypted: true
        };
    }
```
